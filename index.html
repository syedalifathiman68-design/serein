SEREIN is a considered space for the two habits that shape a productive day: deciding what matters before it begins, and reviewing what happened once it ends. Write a few lines and a serverless cloud function answers within moments.

Our approach

Three principles behind every entry

Good days are rarely accidental. SEREIN keeps the practice deliberately small, so it is easy to return to every morning and every evening.

01

Set one clear focus

Name the single outcome that would make today worthwhile. A narrow intention protects your attention from everything competing for it.

02

Reflect without judgement

Record what worked, what resisted you, and what you noticed. Honest observation is more useful than a harsh verdict.

03

Receive a considered reply

Your entry is sent to an AWS Lambda function, which reads it and returns a short, relevant response along with a few facts about your entry.

A day without an intention is a day decided by other people's urgencies.

How it works

From your words to a response in four steps

  1. 1

    You write

    Your entry is checked in the browser. An empty entry is stopped before anything is sent.

  2. 2

    The browser sends

    JavaScript sends your text as JSON, using a POST request, to a public Amazon API Gateway endpoint.

  3. 3

    Lambda processes

    A Python function validates the input, counts the words, identifies the type of entry and prepares a reply.

  4. 4

    The response returns

    A JSON response travels back through the gateway and is displayed on this page.

Under the hood

A serverless architecture, end to end

There are no servers to provision, patch or keep running. Code executes only when a request arrives, and AWS handles the scaling.
